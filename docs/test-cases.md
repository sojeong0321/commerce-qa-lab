# 테스트 케이스와 추적 매트릭스

비즈니스 규칙(BR)과 테스트를 연결한 문서입니다. "이 규칙은 어느 테스트가 보장하는가"와 "이 테스트는 왜 존재하는가"를 양방향으로 확인할 수 있습니다.

**현재 규모:** Unit/서비스/HTTP 125 · API 73 · E2E 7 = **205**

---

## 5. 테스트 설계 기법 적용

| 기법 | 적용 예 |
|---|---|
| **경계값 분석** | 쿠폰 최소 금액 29,999 / 30,000 / 30,001, 재고와 동일 수량 / +1 |
| **동등 분할** | 수량 입력: 정상(1, 99) / 0 / 음수 / 소수 / 문자열 / null |
| **상태 전이** | 주문 PLACED → CANCELED, 쿠폰 AVAILABLE ↔ USED, 이중 전이 차단 |
| **결정 테이블** | 상품 상태(ACTIVE/INACTIVE) × 재고(0/>0) → 구매 가능 여부 |
| **시나리오 기반** | E2E 5개 여정 |
| **부정 테스트** | 모든 실패 경로에서 상태 불변 검증 |
| **변이 테스트** | 23종 주입, 전부 검출 확인 ([결함 사례](defect-examples.md)) |
