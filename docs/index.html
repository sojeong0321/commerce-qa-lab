진행 현황

commerce-qa-lab 단계별 가이드

작은 온라인 쇼핑몰을 직접 만들고, 그 쇼핑몰을 검사 로봇이 자동으로 확인하게 만드는 프로젝트입니다. 각 단계마다 무엇을 만들었고 어떻게 확인했는지 코딩을 몰라도 읽을 수 있게 정리했습니다.

현재 Phase 9까지 완료. 자동 검사 205개가 통과하고, 코드를 올릴 때마다 GitHub가 1분 안에 전부 다시 검사합니다.

지금 상태

현재 동작하는 것

205자동 검사 (모두 통과)
4화면 (상품, 장바구니, 주문 완료, 주문 내역)
14동작하는 API (+ 테스트 전용 1개)

검사 205개의 구성: 순수 계산 38개, 데이터베이스까지 함께 확인 57개, 서버를 띄워 확인 30개, Playwright API 검사 73개, 실제 브라우저 검사 7개입니다. 코드를 GitHub에 올리면 전부 자동 실행됩니다.

npm install       # 준비물 설치
npm run db:setup  # 초기 데이터 넣기
npm start         # http://localhost:3000 에서 쇼핑몰 열기
npm test          # 자동 검사 205개 전부 실행
npm run report    # 검사 결과 보고서 열기
