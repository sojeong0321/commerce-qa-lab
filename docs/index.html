진행 현황

commerce-qa-lab 단계별 가이드

작은 온라인 쇼핑몰을 직접 만들고, 그 쇼핑몰을 검사 로봇이 자동으로 확인하게 만드는 프로젝트입니다. 각 단계마다 무엇을 만들었고 어떻게 확인했는지 코딩을 몰라도 읽을 수 있게 정리했습니다.

현재 Phase 4까지 완료 + 중간 점검 완료. 상품 · 장바구니 · 쿠폰 · 주문 · 취소가 실제로 동작하고, 자동 검사 125개가 통과합니다.

지금 상태

현재 동작하는 것

125자동 검사 (모두 통과)
4화면 (상품, 장바구니, 주문 완료, 주문 내역)
14동작하는 API (+ 테스트 전용 1개)

검사 125개의 구성: 순수 계산 확인 38개, 데이터베이스까지 함께 확인 57개, 서버를 띄워 주소로 요청하는 확인 30개입니다. 브라우저를 여는 정식 E2E 검사와 Playwright 기반 API 검사 스위트는 Phase 5~6에서 추가되고, Phase 7부터 GitHub에서 자동으로 실행됩니다.

npm install       # 준비물 설치
npm run db:setup  # 초기 데이터 넣기
npm start         # http://localhost:3000 에서 쇼핑몰 열기
npm run test:unit # 자동 검사 실행
각 단계 가이드는 이 폴더(docs)에 HTML 파일로 저장됩니다. 파일을 더블클릭하면 브라우저에서 바로 열립니다.
